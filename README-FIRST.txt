HOW TO USE THESE IN GOOGLE AI STUDIO
------------------------------------
1. Open your REMIXED Aura Time project.
2. Open the Code view / project file explorer.
3. If the project supports file upload, add the two folders under:
     public/assets/
   so the final paths are:
     public/assets/celestial-jelly/celestial-jelly-master.png
     public/assets/celestial-jelly/celestial-jelly-pulsing-reference.mp4
     public/assets/celestial-jelly/celestial-jelly-swimming-reference.mp4
     public/assets/living-bloom/living-bloom-master.png
4. If AI Studio does not show a file-upload control, do not guess or paste
   local computer paths into code. Use the project's supported file import
   or GitHub workflow, or ask the assistant to inspect the available
   upload/import controls first.
5. After uploading, ask AI Studio to verify that each file exists and can
   be loaded. Do not ask it to modify the application until verification
   succeeds.
